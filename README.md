# ✈️ Flight Service Platform — FastAPI & React

A full-stack flight reservation platform built using **FastAPI, Python, React.js, and JavaScript**. The application provides a modern web interface for managing flight-related operations, with a high-performance REST API backend.

## 🚀 Overview

The Flight Service Platform is designed to simplify flight reservation operations through a responsive frontend and a Python-based backend. It demonstrates full-stack development, REST API integration, backend architecture, and frontend-backend communication.

## ✨ Features

* **Flight Management:** Manage flight-related information and operations.
* **Flight Search:** Search for available flights based on supported criteria.
* **Booking Management:** Handle flight reservation operations.
* **RESTful APIs:** Backend APIs built using FastAPI.
* **Responsive UI:** Interactive frontend developed with React.js.
* **Frontend-Backend Integration:** Communication between React and FastAPI.
* **API Documentation:** Interactive API documentation generated by FastAPI.
* **Scalable Architecture:** Separated frontend and backend for easier maintenance and future enhancements.

## ⚙️ Installation and Setup

Follow these steps to run the project locally.

### Prerequisites

Install the following:

* Python 3.10 or later, compatible with your dependencies
* Node.js and npm
* Git

### 1. Clone the Repository

```bash
git clone https://github.com/sumit-git204/FlightServicePlatform_Python_fastAPI.git
cd FlightServicePlatform_Python_fastAPI
```

### 2. Set Up the FastAPI Backend

Navigate to the backend directory:

```bash
cd flight_service_FastAPI
```

Create a virtual environment:

```bash
python -m venv venv
```

Activate it on Windows:

```bash
venv\Scripts\activate
```

Install the dependencies:

```bash
pip install -r requirements.txt
```

Start the FastAPI server:

```bash
uvicorn main:app --reload
```

If your FastAPI application entry point is different, replace `main:app` with the appropriate Python module and application variable.

The backend will typically be available at:

* **API Base URL:** http://127.0.0.1:8000
* **Swagger UI:** http://127.0.0.1:8000/docs
* **ReDoc:** http://127.0.0.1:8000/redoc

### 3. Set Up the React Frontend

Open a new terminal and navigate to the frontend directory from the project root:

```bash
cd flight_service_frontend
```

Install the dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

If your project uses Create React App instead of Vite, use:

```bash
npm start
```

Open the local URL displayed in your terminal to access the frontend.

## 🔗 Frontend and Backend Integration

The React frontend communicates with the FastAPI backend through HTTP requests.

Ensure that the frontend API base URL points to the running backend.

For example, if the frontend uses Vite, you can configure the API URL in a `.env` file:

```env
VITE_API_URL=http://127.0.0.1:8000
```

Read the variable in your React application:

```javascript
const API_URL = import.meta.env.VITE_API_URL;
```

Use this base URL when making API requests. The exact configuration depends on how API calls are implemented in your project.

**Important:** Configure CORS on the FastAPI backend if the frontend and backend run on different origins during development.

## 🔐 Environment Variables

Keep credentials and environment-specific configuration in local `.env` files.

For example:

```env
DATABASE_URL=
SECRET_KEY=
```

Use only the variables required by your application.

Do not commit real passwords, API keys, access tokens, or database credentials to GitHub. If the application requires environment variables, document their names in a `.env.example` file without including actual secrets.
